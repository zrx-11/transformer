# Transformer 从零推导 · 交互式学习页面

一个把 Transformer（GPT / BERT / 大语言模型的基础架构）**从初中数学和生活常识开始，一步步推导到专家理解水平**的单文件交互式 HTML 学习资料。

## 这是什么

| 项目 | 说明 |
|---|---|
| 产物 | `Transformer从零推导.html`（单文件，约 700KB） |
| 打开方式 | 用手机或电脑浏览器直接打开即可，无需联网、无需安装任何东西 |
| 目标读者 | 从初中生到大学生，零基础开始学 |
| 学习承诺 | 每个原理不跳步推导；每个概念配生活直觉与数值例子；推导链完整到"低智初中生也能学会"的程度 |

## 核心特点

- **从零推导**：所有前置知识逆推到初中数学（四则运算、函数、向量、概率）和常识公理，再正向推导回 Transformer 全部原理
- **生活直觉**：排队（序列与位置）、自动售货机（函数）、手电筒影子（内积）、查字典（词嵌入）、聚光灯（注意力）……每个抽象概念都有形象类比
- **数值例子**：每个公式都有具体数字代入演算，不是干巴巴的符号
- **卡点模拟**：以"低智商初中生"视角逐节模拟学习过程，找出会卡住的地方并补足（共四轮 51 项检查）
- **公式必渲染**：KaTeX 渲染引擎与全部字体已内联进文件，任何环境打开公式都正常显示，绝不出现 LaTeX 源码
- **移动端优先**：手机屏幕不横向滑动、内容完整展示、无右侧截断

## 使用方法

- **目录**：移动端点击顶部左侧"目录"按钮弹出章节列表；桌面端左侧目录常驻
- **切换章节**：每章底部有"上一章 / 下一章"大按钮；顶部导航栏右侧有 ‹ › 快捷箭头（移动端常驻）
- **推导折叠**：每个推导步骤默认展开，点击标题可折叠；顶部"展开/收起全部推导"按钮可一次性操作
- **知识树**：首页有知识树总览，点击节点可跳转到对应章节

## 技术说明

- **单文件自包含**：CSS、JS、KaTeX 渲染引擎、全部 woff2 字体均内联，无任何外部依赖（CDN 在国内环境下会加载失败导致公式显示源码，故全部内联）
- **无框架**：原生 HTML + CSS + JavaScript，无需构建工具
- **数据规模**：63 个提示框、179 个推导步骤、60 个公式块、7 张表格

## 设计方法（同类任务可复用的工作流）

本项目遵循 `doubao-first-principles-derivation` 技能（技能库中已安装）的六阶段工作流：

1. 逆推前置知识依赖图（根 → 基础 → 工具 → 主干）
2. 正向推导链（每步不跳步）
3. 产物构建（移动端优先、单文件、KaTeX 内联）
4. 卡点模拟（模拟低水平学习者遍历找卡点）
5. 迭代至专家水准（补直觉、补数值例子、补矩阵形状等细节）
6. 自检交付（shot.py 双端截图、公式渲染验证）

## 已知说明

- 交互演示为"推导展开/折叠 + 章节切换"，未包含可拖动的可视化实验（如注意力热力图滑块）
- 数值例子中的数据多为便于理解的假设值，非真实模型参数，文中已注明
